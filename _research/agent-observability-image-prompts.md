# 에이전트 관측성 이미지 제작

built-in image_gen 일러스트4장, 직접 작성 SVG도해5장·차트1장. 전부 폭800px/높이500px 이하, 캡션 없이 각 H2에 배치. 가상의 업무·팀 장면이며 PE사 실사나 실제 시스템 화면이 아니다.

최종 파일: thumbnail.webp, illustration-missing-process.webp, illustration-agentops-team.webp, illustration-observability-workshop.webp, diagram-task-trace.svg, diagram-observability-stack.svg, chart-ramp-improvements.svg, diagram-change-evaluation.svg, diagram-business-metrics.svg, diagram-recording-policy.svg.

SVG는 800×460. WebP는 원본 비율을 유지해 폭800으로 축소. SVG 렌더와 생성 원본을 직접 확인해 글자·연결·차트·인물 자세·화면 방향을 검수했다. Ramp 차트는 개선 전100 지수이며 토큰80~90, 호출85, 세션시간70을 표현한다. 원본은 기본 생성 폴더에 보존하고 배포본을 포스트 폴더에 저장했다.
